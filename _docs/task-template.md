# Task specification template
## Goal
State user story, problem, feature behavior and dependencies.
## Acceptance criteria
Describe models, creation, changes, display, validation and observable done conditions. Include required tests and persistence requirements.
## Out of scope
Name features that are explicitly excluded from this task.
## Constraints
Describe technology, database, routes, UI expectations, security and sequencing. Keep requirements specific enough for engineer and QA to execute independently.
