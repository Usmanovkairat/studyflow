# Create and manage courses

## Goal
As a student, I organize assignments by course.

## Acceptance criteria
- [ ] List courses, create a course, rename it and delete an unused course through the route contract.
- [ ] Trim names; reject blank, over-100-character or case-insensitive duplicate names without database mutation.
- [ ] Deleting a course used by any task is rejected with a clear message and preserves course and tasks.
- [ ] Missing course IDs return 404. Mutation routes require CSRF; deletion requires explicit UI confirmation.
- [ ] Tests verify valid create/edit/delete, invalid names, uniqueness and referenced-course restriction; records remain persisted.

## Out of scope
Color customization, course schedules and cascade deletion.

## Constraints
Depends on 01. Use courses table with foreign-key restriction and consistent navigation/empty states.
