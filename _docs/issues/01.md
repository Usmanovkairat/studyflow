# Bootstrap persistent local application

## Goal
As a student, I can launch StudyFlow locally and keep records across restarts.

## Acceptance criteria
- [ ] Application factory initializes SQLite schema with courses and tasks, enables foreign keys and closes connections after requests.
- [ ] Root page and navigation render successfully with accessible empty states; production data lives in ignored instance directory.
- [ ] Dependencies, environment configuration and localhost run command are documented; setup works from a clean environment.
- [ ] Tests use an isolated temporary database; a second app instance can read data written by the first.
- [ ] Parameterized SQL, escaping, validation helpers and CSRF-protected mutation conventions are available; missing or invalid token mutations are rejected.

## Out of scope
Accounts, course/task CRUD screens and dashboard calculations.

## Constraints
No dependencies. Flask, sqlite3, pytest, HTML/CSS. Models follow architecture.md; no external database or frontend build pipeline.
