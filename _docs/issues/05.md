# Show dashboard and upcoming work

## Goal
As a student, I see workload and urgent work immediately.

## Acceptance criteria
- [ ] Dashboard reports total, unfinished, done and overdue counts across all tasks independently of list filters.
- [ ] Overdue is a due date strictly before the local current date and status other than done; today is not overdue.
- [ ] Upcoming shows earliest five unfinished tasks due today or later, ordered by due_date then id; completed tasks never appear.
- [ ] Each upcoming task links to its detail and displays course, date and priority. Empty dashboard helps create a first course/task.
- [ ] Tests pin the date and cover yesterday/today/tomorrow, todo/in_progress/done, five-item limit and equal-date tie order. UI remains readable on mobile.

## Out of scope
Charts, reminder notifications and workload prediction.

## Constraints
Depends on 03. GET /. Use calendar dates consistently with stored YYYY-MM-DD values; document local-date meaning.
