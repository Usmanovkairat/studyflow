# Search and combine task filters

## Goal
As a student, I find relevant assignments by text, course, status and priority.

## Acceptance criteria
- [ ] Case-insensitive substring search matches task title or notes; supplied course, priority and status filters combine with AND.
- [ ] Empty query returns all tasks and active values remain visible in filter controls. Clear filters restores all results.
- [ ] Results order by due_date ascending then id ascending; an empty result displays a useful message.
- [ ] Invalid filter enums and course values return helpful 400 responses; SQL injection-like search strings are treated as data.
- [ ] Tests include mixed-case text, title/notes matches, each filter, combined filters, no matches, clear filters and stable ordering.

## Out of scope
Pagination, fuzzy search, advanced query language and custom sorting.

## Constraints
Depends on 03. GET /tasks query parameters q, course_id, priority, status. Implement reusable list query so CSV export shares semantics.
