# Export filtered CSV and verify delivery

## Goal
As a student, I download the displayed assignment selection and run the complete app reliably.

## Acceptance criteria
- [ ] GET /tasks/export.csv downloads UTF-8 CSV with id,title,course,due_date,priority,status,notes columns and correct attachment headers.
- [ ] CSV uses the same validated q/course_id/priority/status filters and ordering as the task list; blank selection produces header only.
- [ ] Correctly quote commas, newlines and quotation marks. Neutralize spreadsheet-formula-leading values including whitespace followed by =,+,-,@ and control characters.
- [ ] Automated tests verify filter parity, quoting, headers and formula safety; full automated suite is executed and actual outcomes documented.
- [ ] Complete README provides installation, run, test, demo and backup instructions. QA independently checks complete workflows and records actual results.
- [ ] Local source and docs are committed. Actual GitHub repository/issues are published and closed only if capabilities permit; otherwise delivery explicitly records publication pending with concrete issue payloads and no fabricated links or timestamps.

## Out of scope
Cloud deployment, Excel workbook export and claiming deadline compliance without a supplied deadline.

## Constraints
Depends on 01–05. Use Python csv writer. Keep real remote issue status separate from implementation readiness; all required methodology artifacts must be included.
