# StudyFlow agent instructions
Read `_docs/plan.md`, `_docs/architecture.md`, `_docs/process.md`, `_docs/testing-guidelines.md` and your role in `_docs/team/` before changing the project. This is a single-user Flask/SQLite assignment tracker served on localhost. Follow the six specifications in `_docs/issues/` in dependency order. The orchestrator delegates specification to PM, implementation to software engineer, and independent verification to QA. Ask the user only for essential access or missing requirements.

Do not fabricate user dialogue, test results, issue numbers, remote links, commits or timestamps. Local issue specification filenames are not GitHub issue IDs. Preserve accurate actual publication status in `_docs/publication.md` and the task ledger. Use parameterized SQL, server validation, HTML escaping and CSRF protection for mutations. Do not add authentication, public hosting or unrelated features. Run meaningful tests and record actual outcomes. Close a remote issue only after acceptance criteria pass and implementation is published.
