# StudyFlow

A single-user, local student assignment workspace built with Flask and SQLite.

## Setup

Use Python 3.10 or newer. From the repository folder:

```sh
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell instead: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m flask --app studyflow run --host 127.0.0.1 --port 5000
```

Open http://127.0.0.1:5000. Stop the server with Ctrl+C. The database is initialized automatically in `instance/studyflow.sqlite`; restarting the application preserves data. Back up that file while the server is stopped. `instance/` and the local virtual environment are ignored by Git.

The app factory accepts `DATABASE` and `SECRET_KEY` configuration overrides for isolated tests. Set `STUDYFLOW_SECRET_KEY` to a strong random secret to override the local development key. Otherwise a persistent secret is generated in ignored `instance/secret.key`. `STUDYFLOW_ENV=production` requires an explicit environment secret. The app is designed for trusted localhost use without accounts.

The dashboard uses the local calendar date of the computer running Flask. Open means todo or in progress; overdue means due before that date and unfinished. Today is never overdue. Upcoming shows the earliest five unfinished assignments due today or later, ordered by date then ID. Dashboard totals always cover every assignment.

## Verification

```sh
python -m pytest -q
```

Tests use temporary databases. All mutation routes must submit the session token as `csrf_token`, generated by the template helper `csrf_token()`. Request validation uses shared helpers, SQL values use parameters, and templates escape user content.

## Features and workflow

1. Create courses from **Courses → Add course**.
2. Add assignments with title, course, due date, priority, status and optional notes.
3. Edit details, mark complete or reopen work. Delete requires expanding a confirmation. Courses with assignments cannot be deleted until their assignments are deleted or moved.
4. Search title/notes and combine course, priority and status filters. Unicode search is case-insensitive; percent and underscore are literal characters.
5. See total/open/completed/overdue counts and the next five assignments on Dashboard.
6. Export current filtered results from Tasks as UTF-8 CSV. Spreadsheet formula-leading cells receive an apostrophe for safety; the original database data remains intact.

Names/titles are trimmed; notes retain formatting. Course names are unique with Unicode casefold comparison. Past due dates are valid. All forms protect writes with CSRF, and validation failures keep useful input.

## Demo

For a fresh empty checkout only, while the server is stopped:

```sh
python scripts/demo.py
```

This creates three courses and five assignments relative to today's date. It refuses to add demo records if any course or assignment already exists. Restart Flask and inspect Dashboard, Tasks and Courses. Back up your own database before making any manual changes.
